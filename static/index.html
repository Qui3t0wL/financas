ℹ️ Formatos suportados

O PDF deve ter as colunas DATA LANC · DATA VALOR · DESCRITIVO · DÉBITO · CRÉDITO · SALDO. A aplicação tenta extrair tabelas automáticamente — se o teu banco exporta PDFs com texto seleccionável, funciona na maioria dos casos.
